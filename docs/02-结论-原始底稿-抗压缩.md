# 抗压缩 · 维持连续性

> **建** 2026-10-01 凌晨 ｜ **源**：今晚实测（机制见 `自动压缩-配方与实测.md`）
> **目标**：让一个 agent 在**反复压缩**下，仍然"是同一个"。
> **一句话**：能维持的是 **可追索的连续**，做不到的是 **不变的连续** —— 差别见 §一。
> ★ **总纲（用户 2026-10-03 定）**：**压缩必定磨损；分层通向永恒。**
> 　⚠️ 两个词都要限定：**磨损**磨掉的主要不是内容（那个在盘上、读得回来），是**等级与「为什么」**（§一.2 / §一.3，补不回来）；**永恒**指**可追索**（盘 · 坐标 · **在场者**），不是**不变**。

---

## 一、先说清楚：能维持的是什么

| | 可追索的连续 ✅ | 不变的连续 ❌ |
|---|---|---|
| 内容 | 原来的东西**在盘上**，需要时读得回来 | 内容**一直在上下文里** |
| 来路 | 每条结论**带"去哪儿核"** | 每条结论**自带 why** |
| 归属 | 分得清**谁说的**、什么等级 | 不须分辨 |
| 代价 | 每次要补都花一次往返 | 零（但不可能） |

**为什么"不变"做不到，三条硬边界：**

1. **补回来就是占体积。** 把丢掉的 37 万 token 读回来 ⇒ 上下文又满了 ⇒ **立刻又要压**。补全和压缩**直接对冲**。
   ⇒ 可行形态不是"记得全部"，是**"随时查得到全部"** —— 像人查档案，不像硬盘常驻。
2. **有些东西原文里也没有。** 丢的"过程"原文里有（原文是全的，`prune` 只改表层）；**但"我当时为什么这么判"，原文里只有"我写了什么"** —— 当时没写下来，事后补不回来，而且**事后补的一定长得很像、但不真**。
3. **最要命的一种腐败不是丢内容，是丢等级。** 摘要里**引号同时承担三种含义**（真引用 / 剪短的摘录 / 普通标记），读的人分不出 ⇒ **会把 agent 的推测当成用户的话用**。这种腐败**补不回来**（重建归属要逐条回原文核）。

> **所以目标是：让"这个 agent 是谁"不依赖上下文，而依赖"盘 + 坐标 + 在场者"。**

### 🎯 目标的正名：**不换 agent**

**"逆天改命"的准确含义 = 不换 agent。**

```
默认天命：哑火 / 压缩 → 丢东西 → 换 agent（新 agent 从头养手感）
逆天改命：压缩 → 对账 → 大概补齐 → 不换，接着用
```

**为什么是「大概」补齐 —— 这一层最要紧：**

| | 做法 | 后果 |
|---|---|---|
| **完整补齐** | 把删掉的章节**贴回去**（= 吞原文） | 等于没删 ⇒ 下一轮又得撕下来 ⇒ **和压缩直接对冲** |
| **大概补齐** | **夹一张勘误页** | 几行字 ⇒ **不对冲** |

**而「大概」够用的前提是坐标**：说「**t215 被剪了这 4 处 / 17,041 token**」，而不是「你少了一块」。

**保护的是手感，不是信息** —— 换代传的是信息（别人写的卡，丢了 why）；补齐保的是手感（自己的判断）。
被试原话：「这就是为什么我不想换 agent，手感真的不一样。」

## 二、三条对策（按性价比排序）

### 1. 缺损地图 —— 压缩后第一件事

**材料现成，就在会话记录里**，没人读给 agent 看而已：

```
compaction/prune   →  shadowedSeqs: [3358, 19389, 32151, 440268]
                      shadowedTokenCount: 2262 + 5025 + 2530 + 7224
compaction/start   →  turn: 215
compaction/end     →  error?: "…"   ← 有 error = 那一次失败 = 洞最大的时候
```

**一行就够**：「我在 t215 被剪了 4 处 / 17,041 token；第二次在 t240 成功」。**指针比内容便宜三个数量级**（一行 vs 37 万 token）。

**为什么它是最该先做的**：
- 它把"我不觉得缺"变成"我知道我缺哪几块" —— **这是所有其它对策的前提**
- 它不依赖 agent 的自知（不自知是结构性的，见 §四）
- **它把"用户当指示器"降级成"用户派活"**

⚠️ 尚未做成自动打印，目前要手动读会话记录。

### 2. 带坐标原则 —— 断言必须能还原到"去哪儿核"

- ❌ `1: 有` ← 结论的形状
- ✅ `1: 有（候选#3，用户 12:38 那条）` ← **线索的形状**

适用范围**不止压缩**：摘要、交接卡、日记、规则、agent 的每一句结论。
**判据**：**凡是不能还原到"去哪儿核"的，最后都会被当成结论用。**

⚠️ 这一条与 `AGENTS.md` 的硬约束（**极薄 + 单行 + ≤130 字符**）天然冲突 —— **答案只能是"薄的地方留断言 + 带指针，厚的地方放原文"**。

### 3. 「为什么」当场落 —— 因为它是唯一补不回来的

- 结论：**丢得起**（摘要保、卡里也有、能重推）
- 过程：**丢得起**（原文在盘上，读得回来）
- **"当时为什么这么判"：丢不起** —— 原文里没有，事后补的是编的

⇒ **落盘时优先写"为什么"，而不是写"是什么"。**

## 三、什么活得过压缩（四条件）

1. **短** —— **长度比重要性更能决定生死**（摘要有 8192 上限，AGENTS.md 有 130 字符上限）
2. **成句** —— 未成型的念头、只说了一半的话，第一次压缩就没了
3. **带引号**（如果是别人的话）—— 指令明确保护 `quote verbatim`，且**用户的话保真度最高**
4. **落盘** —— 落在盘上的不归压缩管（`prune` 只改喂进模型的表层，日志一条没动）

| **主模型**（贵） | 判断、决策、判官 B | 上下文会满、会哑火、会腐 |

**qwen 的实测边界（2026-10-01 首次实战）：**

- **首战**（需要语义判断）：**8/12**，错误模式是**字面主义**（沾边说有、不沾边说没有），且**12 条全答、无一条"不确定"**
- **二战**（有标准答案的字面核对）：**8/8**
- ⇒ **题型决定成败**。提示词里**必须显式给出"不确定"选项**，否则它一定在给它的选项里挑一个
- ⇒ **它最好的用处不是答对，是分歧点** —— 跟它顶牛的地方，正是该复核的地方
